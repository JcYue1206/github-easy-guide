# GitHub 小白指南（github-easy-guide）

很多 GitHub 项目看起来简单，下载下来却不知道怎么用。装上这个“技能”后，你的 AI 助手会用大白话帮你把一个项目讲明白：

1. **它能做什么**：两三句话说清楚
2. **一项一项地选**：比如做法、横屏竖屏、时长、风格，每个选项都有简短说明，还会标出推荐项
3. **一步步做**：每一步写清楚点哪里、会看到什么
4. **开工指令**：把你的选择填成一段话，复制给 AI 就能开工

它还会帮你查项目用到的外部网站**现在**的情况：在中国能不能打开、要花多少钱、有什么限制。查不到的就直接问你，不会瞎编。

---

## 第一步：下载

**只需要下载一个文件：`github-easy-guide.zip`。** 它就在这个页面上方的文件列表里，和 README.md 在同一层。点开它，再点右边的下载按钮（一个向下的箭头）。

不用先解压。真要解压，里面是一个 `github-easy-guide` 文件夹，文件夹里只有一个 `SKILL.md`。

> 打不开 GitHub？请找分享给你的人，直接把 `github-easy-guide.zip` 发给你。

---

## 第二步：安装

### 方法一（推荐）：让你的 AI 助手自己装

适用于 WorkBuddy、TRAE、CodeBuddy、Qoder 这类能安装技能的助手。

1. 打开助手，新建一个对话
2. 把 `github-easy-guide.zip` 拖进输入框
3. 复制这句话发给它：

```
帮我把这个压缩包里的技能安装好，装好后告诉我装在哪里、怎么确认已经生效。
```

4. 它回复“装好了”以后，新开一个对话就能用

### 它说装不了？

打开同一层里的 **[INSTALL.md](INSTALL.md)**（完整安装清单），里面有：
- 在 WorkBuddy、TRAE 等界面里点按钮安装
- 手动放文件夹（中国常用的助手、中国以外常用的助手）
- 豆包、元宝、DeepSeek 这类聊天 App 的用法

### 怎么确认装好了

新开一个对话，**不要附任何文件**，只发这句：

```
你现在有没有一个叫 github-easy-guide 的技能？有的话，用一句话告诉我它是干嘛的。
```

它答得出「把 GitHub 项目拆成大白话步骤」就是装好了。答不上来，看 [INSTALL.md](INSTALL.md) 最后一节。

---

## 第三步：怎么用

装好后，在 AI 助手里直接说，比如：
- “我下载了这个项目，不会用：（贴上项目链接）”
- “帮我看看这个项目怎么用：（贴上项目链接）”

只是顺带提到一个链接，或者你在忙别的事时，它不会跳出来打扰你。你说“不用”，它这次就不会再提。

## 示例

拿 GitHub 上一个做火柴人动画视频的项目（stickman-video-director）为例，AI 会先介绍它能做什么，再让你依次选：

① 怎么做（AI 在你电脑上做 / AI 写好你复制粘贴 / AI 替你去网站上做）→ ② 横屏还是竖屏 → ③ 多长 → ④ 什么画风

用到外部网站的选项会注明在中国能不能打开、要不要花钱。最后给你一步步的做法，和一段可以直接复制的开工指令。

> 项目网页打不开时，AI 会请你把网页上的字全选、复制、粘贴给它，照样能帮你。
